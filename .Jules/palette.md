## 2025-04-30 - Focus-visible and ARIA labels for custom icon-only elements
**Learning:** In a highly stylized, dark-themed UI with custom cursor/interaction elements, standard keyboard focus states are often completely overridden or invisible. Furthermore, many interactive elements (like the navigation arrows, menu close button, and social links in this app) are implemented as visually distinct icons but lack descriptive text. Relying purely on hover states excludes keyboard and screen reader users from navigating the site effectively.
**Action:** Always implement a high-contrast `:focus-visible` outline for `button` and `[tabindex]` elements. For custom UI elements lacking visual text labels (like `.nav-btn`, `.ctrl-btn`, etc.), explicitly add `aria-label` attributes to convey their purpose to assistive technologies.
