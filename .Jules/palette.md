## 2024-06-16 - Make Interactive Controls Keyboard Accessible\n**Learning:** The custom UI heavily relies on `<div>` elements (like the hamburger menu) and icon-only buttons for interactions. These elements implicitly lack keyboard accessibility and screen-reader context.\n**Action:** Applied `role="button"`, `tabindex="0"`, `aria-label`, and `keydown` event listeners to non-native controls. Added a global `*:focus-visible` CSS rule to ensure keyboard focus states are visible globally without interfering with mouse clicks.
