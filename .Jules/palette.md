## 2025-02-12 - Missing ARIA Labels on Icon-Only Buttons
**Learning:** Icon-only custom navigation buttons (e.g., .nav-btn, .skill-nav-btn, .bk-nav-btn, .ctrl-btn) in this repository's customized UI lack screen reader context by default, making them inaccessible.
**Action:** Always add descriptive aria-label attributes to these elements to ensure they are properly identified by screen readers.
