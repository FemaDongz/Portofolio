## 2026-06-24 - Navigation Accessibility and Focus Management
**Learning:** In monolithic single-page applications with complex CSS overlays, using `opacity: 0` alone is insufficient for accessibility as it doesn't prevent keyboard focus from entering hidden elements. Combining `visibility: hidden` with `opacity` transitions ensures that interactive elements are removed from the tab order when not active. Additionally, converting stylized `div` elements to semantic `<button>` tags and managing focus explicitly (e.g., focusing the close button when a menu opens) significantly improves the experience for keyboard and screen reader users.
**Action:** Always use `visibility: hidden` or `display: none` for modal/menu overlays to manage tab order correctly. Ensure all custom interactive elements use semantic HTML and provide explicit focus management for modal-like transitions.
