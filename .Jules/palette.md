## 2024-07-02 - Icon-only Controls in Custom UI
**Learning:** Custom interactive elements (e.g., `.nav-btn`, `.skill-nav-btn`, `.ctrl-btn`) in this application's carousels and mini-games use visual symbols (like `<` or `▲`) without descriptive text, making them inaccessible to screen readers.
**Action:** Always add descriptive `aria-label` attributes to icon-only navigation and control buttons within these specialized UI components.
