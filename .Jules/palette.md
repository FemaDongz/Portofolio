## 2025-05-14 - Accessible Stylized Dark-Mode Portfolios
**Learning:** In highly stylized "cyber" or "hacker" themed portfolios, interactive elements (like menus and controls) are frequently implemented using non-semantic `div` tags to avoid default browser styling. This breaks keyboard navigation and screen reader support. Additionally, standard focus rings are often invisible against dark backgrounds or clipped by containers with `overflow: hidden`.
**Action:** Convert interactive `div`s to `<button>` tags with CSS resets (`background: none; border: none; padding: 0; font-family: inherit; cursor: pointer;`) to maintain the aesthetic. Implement a global high-contrast `:focus-visible` rule using a vibrant accent color (e.g., `#31a8ff`) and a negative `outline-offset` (e.g., `-2px`) to ensure the focus indicator is both visible and contained within the element's boundaries.
