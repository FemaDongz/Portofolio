## 2026-06-24 - Semantic Hamburger & Full Component Initialization
**Learning:** Stylized portfolios often use `div` elements for interactive components (like hamburger menus) to bypass default browser styling. However, converting these to semantic `<button>` tags with CSS resets is the most robust way to ensure keyboard and screen reader accessibility without sacrificing visual design. Additionally, JavaScript-driven metadata displays (like project carousels) must be fully initialized with the first data item on load; merely linking DOM elements to variables is insufficient if the injection logic only triggers on interaction.
**Action:** Always audit for non-semantic interactive elements and convert them to buttons with `*:focus-visible` high-contrast outlines. Ensure all component render functions (e.g., `renderBook(0)`) are called during the initialization phase to prevent empty or default placeholder states on first load.
