## 2026-06-14 - Semantic Buttons and Global Focus States
**Learning:** In stylized, custom-built portfolios, interactive elements are often implemented as `div` or `span` for ease of styling, which breaks keyboard navigation and screen reader support. Converting these to semantic `<button>` tags with CSS resets (`background: none; border: none; padding: 0; cursor: pointer; font-family: inherit;`) is the most robust way to restore accessibility without impacting the visual design.
**Action:** Identify non-semantic interactive elements (e.g., hamburger menus, carousel arrows) and convert them to `<button>` with descriptive `aria-label` attributes. Implement a global `:focus-visible` style with high contrast (e.g., `outline: 2px solid #fff; outline-offset: 4px;`) to ensure clear navigation feedback for keyboard users.
