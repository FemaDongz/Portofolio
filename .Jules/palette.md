# Palette Journal - Portofolio

## 2025-05-14 - Initial Audit
**Learning:** The portfolio is highly animated and uses a Photoshop-like dark/light theme. Accessibility is currently minimal: icon buttons lack labels, and interactive elements (like the hamburger menu) are not semantic buttons.
**Action:** Use semantic `<button>` elements for the hamburger menu and add `aria-label` to the logo/home button. Ensure focus states are visible and don't clash with the dark background.
