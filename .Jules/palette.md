## 2024-06-18 - Missing ARIA Labels and Keyboard Access on Custom UI Elements
**Learning:** Custom interactive elements (like icon-only `.clip-btn`, `.nav-btn` buttons, and `div` elements acting as buttons like `#hamburgerBtn`) in this application frequently lack semantic accessibility attributes (`role="button"`, `tabindex="0"`, `aria-label`) and do not trigger on standard keyboard interactions (Enter/Space) natively. Relying only on visual context or default browser behavior for `div` tags breaks screen reader navigation and keyboard usability.
**Action:** Always verify that custom buttons and interactive `div`s have `aria-label`s, appropriate roles, `tabindex`, and explicitly attached `keydown` listeners for 'Enter'/'Space' to ensure they are accessible. Add global `:focus-visible` styles if missing.
