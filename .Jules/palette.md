## 2026-03-31 - Keyboard Accessibility for Interactive Widgets\n**Learning:** Custom interactive widgets like swipe carousels often rely purely on pointer events (mouse/touch), making them completely inaccessible to keyboard users.\n**Action:** When working with such widgets, manually add `tabindex="0"`, relevant ARIA roles (like `role="region"`), an `aria-label`, and explicit `keydown` event listeners to support standard keyboard navigation (e.g., Arrow keys).
