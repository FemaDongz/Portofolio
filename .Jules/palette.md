## 2026-06-14 - Semantic Button Conversion and Dark Theme Focus States
**Learning:** Dark-themed portfolios often use non-semantic elements like `div` for interactive controls to avoid default browser styling, which breaks keyboard navigation and screen reader support. Using semantic `<button>` elements with a comprehensive CSS reset allows for accessibility without compromising the "cyber" or custom aesthetic. Additionally, a global `:focus-visible` style with `outline-offset` is essential in dark themes to ensure the focus indicator is visible and doesn't blend into the background or overlap the element's border.
**Action:** When auditing stylized portfolios, always convert `div` or `li` elements with click handlers into semantic `<button>` tags. Apply a global `:focus-visible { outline: 2px solid #fff; outline-offset: 4px; }` to guarantee AAA contrast and clear navigation visibility across all viewports.
