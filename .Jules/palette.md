## 2025-05-14 - Accessibility and Focus States in Dark-Mode Portfolio
**Learning:** In a highly stylized dark-mode portfolio, standard browser focus rings are often invisible or inconsistent. Using the project's primary accent color (#31a8ff) with `*:focus-visible` ensures clear navigation cues for keyboard users without compromising the aesthetic. Additionally, when refactoring for accessibility (e.g., adding labels), it is critical to preserve non-interactive `div` containers that serve as anchors for JavaScript-driven dynamic content (like titles and pagination).
**Action:** Always implement a custom `:focus-visible` style that matches the site's accent color and verify that all interactive elements are semantic (buttons/links). Carefully audit the DOM for ID-based JavaScript hooks before performing structural refactors to avoid breaking dynamic UI components.
