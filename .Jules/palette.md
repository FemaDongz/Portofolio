## 2026-06-24 - [Micro-UX & Accessibility Initialization]
**Learning:** Dark-themed portfolios often lack high-contrast focus indicators and semantic interactive elements (like converting divs to buttons), which significantly impairs keyboard navigation. Using global focus styles and semantic HTML ensures consistent accessibility.
**Action:** Always implement ':focus-visible' with high-contrast outlines and prioritize semantic '<button>' elements over 'div's for interactive components.
