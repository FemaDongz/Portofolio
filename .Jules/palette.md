# Palette's Journal - UX & Accessibility Learnings

## 2026-06-24 - Semantic Interactive Elements in Creative Portfolios
**Learning:** Creative portfolios often sacrifice accessibility for aesthetics by using non-semantic elements (like `div`) for interactive controls, which breaks keyboard navigation and screen reader support.
**Action:** Always use semantic `<button>` elements for interactive controls and provide descriptive `aria-label` attributes for icon-only buttons.
