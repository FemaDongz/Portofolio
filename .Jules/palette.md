## 2024-05-24 - Interactive Custom UI Elements lack ARIA Labels
**Learning:** Icon-only and custom interactive elements (e.g., `<button>` elements like `.nav-btn`, `.skill-nav-btn`, `.bk-nav-btn`, `.ctrl-btn`, and `<a>` elements like `.clip-btn` and the hamburger menu) in this repository's customized UI lack descriptive `aria-label` attributes, making them inaccessible to screen readers.
**Action:** Always add descriptive `aria-label` attributes to icon-only and custom UI elements.
