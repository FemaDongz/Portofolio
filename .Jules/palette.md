## 2025-05-15 - [Semantic Refactoring & Focus Management]
**Learning:** In highly customized, "cyberpunk" or non-standard themed UIs, interactive elements are often implemented as `div` or `img` tags, losing keyboard accessibility. Converting these to `<button>` tags requires a robust CSS reset (background, border, padding, and especially `font-family: inherit`) to maintain the visual aesthetic while enabling screen reader and keyboard support. Additionally, a global `:focus-visible` rule provides a consistent accessibility anchor across disparate UI components without disrupting the visual experience for mouse users.
**Action:** Always audit icon-only controls for ARIA labels and ensure all click-targets are semantic `<button>` elements with `:focus-visible` indicators.
